# Vira — Privacy Policy

Public privacy policy page for the **Vira** Android app (Türkçe + English).

Live: https://azadky.github.io/vira-privacy/

Vira lets you scroll short-video feeds hands-free — with a head tilt, a blink
or a spoken command. The app has no internet permission; camera frames are
processed on the device and never leave it.
